The code reference is the **2021 IRC energy provisions as amended by Pennsylvania**, climate zone 5A
([34 Pa. Code §403.21](https://www.pacodeandbulletin.gov/secure/pacode/data/034/chapter403/s403.21.html)).
The architect should confirm the permit requirements and compliance path with Pittsburgh.

The Code Minimum case uses the amended whole-assembly U-factors, U-0.30 windows, 3.0 ACH50 and an
R-10 basement slab. It is a comparison case, not a code-compliance submission.

The architect's narrative sets **2024 IECC prescriptive insulation levels** as a design minimum.
Confirm whether to keep that requirement. If so, check the sloped roof against it first.

The owners' **[HERS Index](https://www.hersindex.com/) target of 25 or lower** needs a rating by their rater (lower scores
mean a more efficient home); this model cannot
produce that score. Write our **1.0 ACH50** target into the construction documents, with an early
air-barrier test and a final blower-door test.
