This report is a design-phase energy analysis of the Waterman Residence in Pittsburgh, designed by
[mossArchitects](https://www.mossarc.com/). We built a whole-building energy model of the house and
used it to test five design options. The results are meant to guide decisions on the envelope,
windows and mechanical systems while the design is still flexible.

The first option is a code-minimum reference. The second is the house as currently drawn. Each option
after that adds one set of improvements to the one before, so the effect of each step is clear.

### Our recommendation

We recommend developing the **Phius 2024** option, named for the [Phius](https://www.phius.org/phius-certification-guidebook) passive-building
targets it was tested against. It combines very tight construction, better
windows and a high-efficiency ventilation system with heat and moisture recovery.

### Key findings

- **Energy use.** It uses about **28% less electricity** than the house as drawn. See
  [Site energy](/energy_model/#site-energy).
- **Heating and cooling.** It needs about **half the peak heating** of the house as drawn, which means
  smaller equipment. See [Energy targets](/energy_model/#passive-house-thresholds).
- **Future climate.** At the owners' request, the analysis uses projected weather for **2040 to 2059**.
  See [Future Climate](/future-climate/).
- **Power outages.** In a week-long outage the house stays within the winter safety limits, though
  the rooms get cold. In summer, heat and humidity pass the safety limit on three days. Deciding what backup power should cover is one of the main open
  questions. See [Resilience](/resilience/).

### What comes next

The biggest open choices are where to insulate the basement and which windows to buy. Each section
lists the decisions that belong to it.
